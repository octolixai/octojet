def merge_sorted_lists(list1: list, list2: list) -> list:

    Args:

        list2: Second sorted list.

A mutex is a locking mechanism that allows only one thread to access a critical section at a time, requiring the same thread that acquired the lock to release it. In contrast, a semaphore is a signaling mechanism that uses a counter to control access to a resource, allowing multiple threads to access it up to a specified limit. While a mutex is strictly binary and enforces ownership, a semaphore can be binary or counting and does not require the releasing thread to be the same as the acquiring thread. Therefore, mutexes are primarily used for mutual exclusion, whereas semaphores are often used for resource counting or thread synchronization.
